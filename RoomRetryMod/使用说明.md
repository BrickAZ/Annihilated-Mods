# 重打当前房间 v1.0.1

## 安装

测试环境为 Windows x64、Steam Build 26646212 和 MelonLoader 0.7.3。找到你电脑上含 `Annihilated.exe` 的游戏目录。Steam 用户可通过游戏库的「管理 → 浏览本地文件」打开。

1. 按 [MelonLoader 官方安装说明](https://github.com/LavaGang/MelonLoader/blob/v0.7.3/README.md#requirements) 给游戏安装 0.7.3。如果加载器提示缺少 .NET，按官方说明安装 .NET 6 Desktop Runtime（Windows x64）。首次配置后，正常启动游戏并等到标题界面。
2. 退出游戏并解压 ZIP。将包内的 `Mods` 文件夹合并到游戏目录，确认 DLL 位于游戏目录的 `Mods/AnnihilatedRoomRetry.dll`。已安装本仓库杯赛包的玩家可以直接使用随包附带的同版 DLL。
3. 按平时的方式启动游戏。

## 使用

进入一场新战斗时，Mod 会在战斗脚本执行前记录检查点。检查点保存好后，战斗中按 **F9** 可以回到本场开头。普通游玩可以反复重打同一场。

检查点使用独立的 `AnnihilatedRoomRetryCheckpoint` 存档槽。进入下一场战斗时会替换这个槽。退出游戏或读入其他存档后，需要进入一场新战斗才会重新启用 F9。少数没有经过共用战斗入口的战斗可能没有检查点。

通过杯赛入口启动时，F9 由支持重打配额的杯赛 Mod 接管，能否使用及每次罚秒由当届规则决定。

## 卸载

退出游戏，删除游戏目录中的 `Mods/AnnihilatedRoomRetry.dll`。
