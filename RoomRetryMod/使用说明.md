# 重打当前房间 v1.0.1

适用于 Windows x64、Steam Build 26646212。先给游戏安装 [MelonLoader 0.7.3](https://github.com/LavaGang/MelonLoader/releases/tag/v0.7.3)，并正常启动一次，让加载器生成互操作程序集。退出游戏，将压缩包内的 `Mods` 文件夹合并到含 `Annihilated.exe` 的游戏目录。如果杯赛包已安装同版 DLL，可以直接使用。

通过 Steam 正常启动《勇者小队全灭了》。进入战斗时，Mod 会在战斗脚本执行前自动记录一个检查点。战斗中按 **F9** 会读回这个检查点，从第一回合重新打。可以反复重打同一场。

检查点使用独立的 `AnnihilatedRoomRetryCheckpoint` 存档槽。进入下一场战斗时会替换这个槽。退出游戏或读入其他存档后，需要进入一场新战斗才会重新启用 F9。杯赛 v0.3.7 起由当届比赛的 F9 次数限制决定能否重打，使用旧版杯赛时 F9 保持禁用。正常游戏仍可反复重打。

少数没有经过共用战斗入口的战斗可能没有检查点。当前版本在 Steam Build 26646212 和 MelonLoader 0.7.3 下进行了游戏内测试。

卸载时先退出游戏，再删除游戏目录内 `Mods\AnnihilatedRoomRetry.dll`。
