# 重打当前房间 v1.0.1

## 安装

已在 Windows x64 的 Steam Build `26646212`、`26705080` 和 `26845264` 上使用 MelonLoader 0.7.3 验证。Steam 用户可通过游戏库的「管理 → 浏览本地文件」找到含 `Annihilated.exe` 的游戏目录。

1. 退出游戏，完整解压 ZIP，双击 `一键安装.cmd`。如果未自动找到游戏，请选择含 `Annihilated.exe` 的目录。
2. 安装器会联网补齐 MelonLoader 0.7.3 和便携版 .NET 6，并安装 `Mods/AnnihilatedRoomRetry.dll`。杯赛包已附带同版 DLL。
3. 按平时的方式启动游戏。首次启动加载器时，请等到标题画面。

## 使用

进入一场新战斗时，Mod 会在战斗脚本执行前记录检查点。检查点保存好后，战斗中按 **F9** 可以回到本场开头。普通游玩可以反复重打同一场。

检查点使用独立的 `AnnihilatedRoomRetryCheckpoint` 存档槽。进入下一场战斗时会替换这个槽。退出游戏或读入其他存档后，需要进入一场新战斗才会重新启用 F9。少数没有经过共用战斗入口的战斗可能没有检查点。

通过杯赛入口启动时，F9 由支持重打配额的杯赛 Mod 接管，能否使用及每次罚秒由当届规则决定。

## 卸载

退出游戏，删除游戏目录中的 `Mods/AnnihilatedRoomRetry.dll`。
