# 《勇者小队全灭了》剧情回放与 CG 画廊 Mod v1.2.0

正常启动游戏，标题界面右下角有 **剧情回放** 和 **CG 画廊**。两处入口都包含全路线剧透。

## 剧情回放

- 在左侧选序章或角色路线，在上方选 **剧情场景** 或 **结局回放**。本版收录 38 个回放条目，标为「尾声」的条目从对应的剧情尾声开始，标为「结局演出」的条目从原版的结局演出开始。
- 从列表上方选 **长发主角** 或 **短发主角**，再打开场景。立绘、头像、对应版本的 CG 和相关对白变量会随之切换。序章开场里的原版外观选项仍可现场选择。
- 点条目后会打开一个独立的游戏窗口。按原版操作推进对白，遇到选项时直接选择。根据电脑性能，启动回放和载入剧情可能需要几秒。
- 播完会自动关闭回放窗口。中途可以按 **Esc** 或点「退出回放」。退出后接着使用原窗口里的场景列表。
- 回放窗口使用独立存档目录，原窗口继续保留正式存档。回放会跳过原版流程里的保存窗口、自动存档和剧情成就命令。
- 依赖进场布景的回放会先让原版脚本搭好对应层的背景、粒子、镜头起点和进场音乐，再开始对白。剧情中的切景和音乐变化继续按原脚本执行。

## CG 画廊

- 原有 591 张原图可以按路线、阶段或分支筛选，也可以用「全部原图」查看。
- 原图和剧情实景都显示中文标题。连续画面按事件和镜头区分，可用 **全部外观**、**长发** 和 **短发** 筛选。两种外观共用的原图在两边都能看到。
- 「剧情实景」收录原版播放器已经渲染出的画面，包括当时的背景、角色图层、镜头构图、特效和画面上显示的对白。正常游玩和剧情回放都能积累实景。重进画廊可看到新收录的画面，首次使用时从空列表开始。
- 重看此前缺少布景的片段后，画廊会优先显示新收录的画面。旧截图依然保存在原有文件夹里。
- 点击缩略图放大。按 **← / →** 或点按钮切图。
- 在看图界面点击 **自动播放** 或按 **空格**，每张显示约 3 秒，播到当前筛选结果的最后一张停止。再次按空格可暂停。
- 按 **Esc** 从大图回缩略图，再按一次回标题。两个画面也都有返回按钮。

实景文件储存在游戏目录的 `UserData/AnnihilatedGallery/StoryCG`。实景来自游玩时稳定显示的 CG 时刻，覆盖随实际观看的剧情而增加。通过杯赛专用入口启动时，这两个入口隐藏。

## 安装与卸载

适用于 Windows x64、Steam Build 26646212。先给游戏安装 [MelonLoader 0.7.3](https://github.com/LavaGang/MelonLoader/releases/tag/v0.7.3)，并正常启动一次，让加载器生成互操作程序集。退出游戏，将压缩包内的 `Mods` 文件夹合并到含 `Annihilated.exe` 的游戏目录，再从 Steam 启动。卸载时退出游戏并删除 `Mods/AnnihilatedGallery.dll`。

## 源码

从源码构建时，给 `dotnet build` 传入 `-p:GameRoot=你的游戏安装目录`。构建使用仓库内已有的公开索引和本机生成的互操作程序集。`ReplayCatalog.json` 定义回放的脚本起止位置和开场变量，`gallery_titles.py` 定义中文图名。需要重建美术索引时，在本机准备资源清单和脚本行号导出，再运行 `python build_catalog.py <catalog.bin> <资源清单.csv> <scripts.json> GalleryCatalog.json --story-marks StoryCgMarks.json`。
