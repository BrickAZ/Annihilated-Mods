# 杯赛裁判台使用说明

完整解压杯赛 ZIP，在解压目录双击 `Cup-Referee.html`。浏览器会在本机读取成绩文件。

1. 在左侧点「读取规则 JSON」，选择主办方游戏目录里的 `UserData/AnnihilatedCup/cup.json`，或选择主办方已核对的同届参考成绩。核对规则、Mod 版本和游戏构建后点「应用当届规则」。
2. 在右侧批量选择或拖入选手成绩。点「有疑点」筛选，再点本局编号查看差异和时间轴。用同一个八位编号核对录像，也可以在详情里填写选手名。
3. 在「暂定排名」区点「导出 CSV」。有疑点的成绩暂不入榜。同组内，通关按用时排名，未通关按最远进度排名，同成绩并列。

想自己试一遍，可以在「读取规则 JSON」中选 [example-ritual.json](examples/example-ritual.json)，应用规则，再把同一个文件作为成绩导入。文件里的比赛、运行编号和时间均为虚构示例。

正式比赛请在开赛前核对选手实际安装的游戏构建。杯赛 v0.4.12 的成绩 JSON 中，`GameBuild` 写的是该 Mod 面向的构建 26705080。
